# 太空侵略者 (Space Invaders)

## 项目简介
这是一个使用纯 HTML、CSS 和 JavaScript 实现的经典太空侵略者游戏。

## 功能说明

### 游戏功能
- **玩家控制**：使用键盘方向键（← →）控制太空船左右移动
- **射击系统**：按空白键发射子弹攻击敌人
- **敌人系统**：4行 × 8列共32个敌人，会随机发射子弹
- **碰撞检测**：子弹与敌人、敌人与玩家的碰撞检测
- **计分系统**：每击毁一个敌人得10分
- **游戏重置**：按 R 键可以重新开始游戏
- **游戏结束**：敌人到达玩家位置或玩家被击中时游戏结束
- **关卡推进**：消灭所有敌人后，会自动生成新一波敌人

### 技术特点
- 纯前端实现，无需后端服务器
- 使用 HTML5 Canvas 进行游戏渲染
- 使用 requestAnimationFrame 实现流畅动画
- 响应式设计，游戏画面居中显示
- 复古风格的绿色霓虹灯视觉效果

## 控制方式
- `←` `→` 方向键：移动太空船
- `空白键`：发射子弹
- `R` 键：重新开始游戏
