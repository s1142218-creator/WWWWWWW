# 太空侵略者 (Space Invaders)

## 專案簡介
這是一個使用純 HTML、CSS 和 JavaScript 實現的經典太空侵略者遊戲。

## 功能說明

### 遊戲功能
- **玩家控制**：使用鍵盤方向鍵（← →）控制太空船左右移動
- **射擊系統**：按空白鍵發射子彈攻擊敵人
- **敵人群組**：4行 × 8列共32個敵人，會隨機發射子彈
- **碰撞檢測**：子彈與敵人、敵人與玩家的碰撞檢測
- **計分系統**：每擊毀一個敵人得10分
- **遊戲重置**：按 R 鍵可以重新開始遊戲
- **遊戲結束**：敵人到達玩家位置或玩家被擊中時遊戲結束
- **關卡推進**：消滅所有敵人後，會自動生成新一波敵人

### 技術特點
- 純前端實現，無需後端伺服器
- 使用 HTML5 Canvas 進行遊戲渲染
- 使用 requestAnimationFrame 實現流暢動畫
- 響應式設計，遊戲畫面居中顯示
- 復古風格的綠色霓虹燈視覺效果

## 控制方式
- `←` `→` 方向鍵：移動太空船
- `空白鍵`：發射子彈
- `R` 鍵：重新開始遊戲
